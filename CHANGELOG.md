# Changelog

## 0.1.0 — 2026-11-11

First version.

- Config flow: server URL and optional API token, reconfiguration.
- Sensors: color today, tomorrow, D+2, D+3, D+4 (with date, source and probabilities), white and
  red days left, success rates (overall, season, month, last 7 days, per horizon), diagnostics.
- Binary sensors: red day expected, white day expected (D+1 to D+4).
- Buttons: recompute the forecast, retrain the models.
- Diagnostics with the token redacted.
